# Content Strategy

## Content Pillars

### 1. Technical Excellence
**Message**: "Proven ability to build production-grade systems"
- Focus on technical depth, not breadth
- Showcase complex projects (neural networks, e-commerce)
- Highlight cloud architecture knowledge
- Demonstrate security-first thinking

### 2. Growth Mindset
**Message**: "Continuous learning and skill development"
- AWS certifications timeline
- Progression from ML to full-stack to cloud
- Hackathon participation
- Fellowship completion

### 3. Global Impact
**Message**: "Nepal-based developer with global ambitions"
- Local context (Kathmandu-based)
- International technical standards
- Global tech interests (cybersecurity, fintech, agritech)
- Multi-platform presence

### 4. Recruiter Ready
**Message**: "Hireable, professional, and engaged"
- Clear technical skills
- Professional certifications
- Project portfolio with links
- Easy contact methods
- Updated CV/resume

## Tone & Voice

- **Professional** but approachable

- **Forward-looking** and ambitious

## Content Organization

### Hero Section Content Strategy

**Goals**:
- Immediate clarity of who you are
- Create curiosity about projects
- Multiple entry points to explore
- Social credibility

**Key Elements**:
- Name prominent (memory anchor)
- Roles emphasize versatility
- Buttons offer different paths
- Social links build trust

### Projects Showcase Strategy

**Selection Criteria**:
1. **Technical Depth**: Shows complexity, not just volume
2. **Diversity**: ML, backend, full-stack coverage
3. **Completeness**: Full implementation, not theory
4. **Relevance**: Aligns with target roles/companies
5. **Actuality**: Real projects, not tutorials

**Presentation**:
- Clear problem statement
- Technical approach highlighted
- Technology stack visible
- GitHub link prominent
- Key metrics/achievements listed

### Certifications Strategy

**Presentation Order**:
1. AWS Cloud Practitioner (industry standard)
2. AWS Architecture (advanced credential)
3. Fellowship (current commitment)
4. Other achievements (secondary)

**Key Info**:
- Issuing organization
- Completion date/status
- Verification badge (if available)
- Highlight major certifications

### About Section Strategy

**Content Arc**:
1. **Hook**: What makes you interesting
2. **Context**: Where you come from
3. **Mission**: What you're building toward
4. **Call-to-action**: Explore more

**Stats Strategy**:
- Numbers that matter (not vanity metrics)
- Current state, not inflated claims
- Supports narrative
